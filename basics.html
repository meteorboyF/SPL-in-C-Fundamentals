1Structure of a C program

A C file is a list of #includes (libraries you want to use) followed by functions. The computer always starts at main() and runs its statements top to bottom. Every statement ends with ;, and { } group statements into a block.

Compile and run (terminal)
gcc hello.c -o hello     // C   (use g++ for C++)
./hello

Overflow
If a result goes beyond the range of its type, it wraps around to a wrong value without any error. On LeetCode this is the most common reason for Wrong Answer on large inputs. When numbers can pass about 2 × 10⁹, use long long.

3Input & output

printf("format", values…) prints the format string and replaces each % placeholder with the next value. scanf("format", &vars…) does the opposite: it reads what the user types into the variables. The & passes the variable’s address, so scanf can write into it.

5if / else

Classic mistakes
  • if (x = 5) assigns 5 and is always true. Use ==.
  • if (x > 0); — the stray semicolon ends the if right there.
  • 1 < x < 5 does not mean what it does in maths. Write x > 1 && x < 5.

6switch

Use it when one value is compared against many constants. Each case is a jump target, and break leaves the switch.

7Functions

A function is a named piece of code with inputs (parameters) and one output (the return value). LeetCode problems are always written as a function, so get used to the shape returnType name(params) { … return value; }.
