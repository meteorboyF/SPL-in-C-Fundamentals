How to use these notes

1 · Read the idea
Each problem starts with how to think about it: the table, the formula, or the invariant. Try writing the code yourself before you open the solution.
2 · Step through it
Press Step ▶ (or the → key). The yellow line is the one about to run. The box on the right tells you what it did, with the real values filled in.
3 · Trace it yourself
Press 🎯 Trace it myself to blur the values, predict the next one, then click to reveal it. The Trace table tab is your paper trace, built for you.

What the visualiser shows

panelwhat it tells you
Codethe line that runs now (yellow). Click any line to jump to the next time it runs.
Nowwhat the line did (row < n → 2 < 5 → true) and why the line is there
Variablesevery stack frame and variable. Changed values flash, and arrays are drawn as boxes
Outputthe console. What this step printed is highlighted, and your typed input is green
Pattern grid(patterns) which cell each printf filled, with spaces shown as dots
Row analysis(patterns) spaces and characters counted for every line, so you can find the formula
Trace tableone row per change: the table you would draw on paper

The visualiser runs a small C interpreter in your browser. Every program on this site is checked to print exactly what gcc prints.
