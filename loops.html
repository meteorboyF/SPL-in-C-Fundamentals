Loops & nested loops

A loop repeats a block of code. Almost every problem from here on is “loop over something and keep track of something”. Every example below runs in the visualiser: step through it and watch the condition being checked on each pass.

1The for loop

for (init; condition; update) {
    body
}
partrunsjob
initonce, at the startcreate / set the counter
conditionbefore every passtrue → run the body, false → leave the loop
bodyafter each true checkthe work
updateafter every bodymove the counter (i++, i += 2, i /= 10 …)

The order is init → check → body → update → check → body → update → … → check (false) → leave. The check runs one more time than the body: for 4 passes it runs 5 times, and the last check is the one that fails.

2The while loop

Use while when you don’t know how many times the loop will run, only when to stop: “while there are digits left”, “while b is not 0”. A for loop is just a while with its init and update gathered on one line.

3The do-while loop

The body runs first and the condition is checked after, so the body always runs at least once. It is rarely needed, but it is the right tool when the first pass must always happen.

5Nested loops

A loop inside a loop. The inner loop runs completely for every single pass of the outer loop, so the total work is (outer passes) × (inner passes). If the inner limit depends on the outer variable (j <= i), the inner loop runs a different number of times on each row. That is exactly how triangle patterns work.

Counting iterations
  • i: 0..n, j: 0..n → n²
  • j: 0..i → 1+2+…+n = n(n+1)/2 ≈ n²/2
  • j: i+1..n (pairs) → n(n−1)/2
  • j *= 2 inner → n log n
Loop bugs
  • for (...); with a stray semicolon makes the body an empty statement.
  • Forgetting the update in a while → infinite loop. The visualiser stops after 30 000 steps.
  • Reusing the same variable (i) in both the outer and inner loop.

6How to trace a loop by hand

  1. Draw a table: one column per variable, plus one for the output.
  2. Write a new row every time a variable changes. Write the check result (T/F) for the loop condition.
  3. Stop when the condition is false and write the final output.

Every visualiser has a Trace table tab that builds exactly this table, and a 🎯 Trace it myself button that blurs the values so you can predict each one before checking.
