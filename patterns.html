Patterns

Patterns are the best practice for nested loops. They look like 50 different puzzles, but there are really only 3 methods. This page teaches the 3 methods first, then groups every pattern (including all the ones from your repo) by the method it needs, from the solid square up to the spiral matrix.

★How to solve any pattern

The 4-step routine (works every time)
  1. Count the rows → that is the outer loop: for (row = 0; row < ROWS; row++). Inside it, the last statement is printf("\n").
  2. Split one row into parts: spaces, then stars, then maybe spaces/numbers again. Each part gets its own inner loop, one after the other (not inside each other).
  3. Make a table with one line per row: row number → how many of each part. Find the formula in terms of row and n. These formulas are your inner loop limits.
  4. Decide what to print in each cell: a star, col + 1, row + 1, a letter 'A' + col, a counter …

Every problem below has a Pattern grid tab in its visualiser. It shows which cell each printf fills, and grey dots mark the spaces that your code really printed. The Row analysis tab builds the step-3 table for you by counting the spaces and characters in every line.

Finding the formula quickly
  • The count goes up by 1 each row → it is row + c. Down by 1 → c − row. Up by 2 → 2·row + c.
  • Find c by looking at row 0.
  • Check: in a centred or right-aligned pattern, spaces + stars should add up to a fixed width.

Method 2 — Grid method (letters, hollow shapes)

Use it when the stars are scattered: loop over every cell of a bounding box and decide each cell with an if. A star goes where the cell lies on a line of the shape:

line in the boxcondition
top / bottom rowrow == 0 / row == n - 1
left / right columncol == 0 / col == n - 1
middle row / columnrow == n / 2 / col == n / 2
\ diagonalrow == col
/ diagonalrow + col == n - 1
chessboard colour(row + col) % 2 == 0

Combine them with ||: the letter Z is row == 0 || row == n-1 || row + col == n-1. Hollow shapes are “solid shape loops + border test”.

Method 3 — Mirror method (diamonds, butterflies)

Use it when the bottom half mirrors the top half. There are three ways, from easiest to most elegant:

  1. Two loops: write the top half, then write the bottom half as a separate loop (skip the shared middle row).
  2. One loop + if: loop 2n − 1 rows, and compute k = row < n ? row + 1 : 2n − row − 1.
  3. One loop + abs(): loop i from −(n−1) to n−1. Then abs(i) is the distance from the middle row, and it goes 3 2 1 0 1 2 3 by itself.

Why patterns go wrong (check these first)
  • 0-based vs 1-based mixing: if row starts at 0, the first row has row + 1 stars. If it starts at 1, it has row stars. Choose one style and keep it for the whole program.
  • < vs <=: col < k runs k times, col <= k runs k + 1 times.
  • printf("\n") in the wrong place: it belongs after all the inner loops and inside the outer loop.
  • Nesting the parts: the space loop and the star loop come one after the other. Putting one inside the other multiplies the counts.
  • Hollow shapes without spaces: inside cells must print " ", otherwise the right border shifts left.

Count method with one part. The inner limit depends on row.

CRight-aligned triangles

Count method with two parts: spaces, then stars.

DAlphabet / character triangles

Same shapes. The value is a char, which is just a number you can add to.

ECounter & parity patterns

The value comes from a running counter or from even/odd (% 2).

FPyramids

Centred rows with odd widths 2·row + 1, or the “star + space” trick.

GDiamonds, hourglass, butterfly & mirrors

Mirror method: two halves, or one loop whose formula changes at the middle row.

HHollow shapes

Loop over the solid shape and print a star only on its border.

ILetter shapes (grid method)

A bounding box and one condition per stroke of the letter.

JMixed & hard

Two or three methods at once, plus abs(), min() of distances, binomials, and a 2D array.
